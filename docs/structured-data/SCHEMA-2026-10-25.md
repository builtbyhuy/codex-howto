## Complete examples shipped in HTML

{"@context":"https://schema.org","@type":"WebSite","@id":"https://builtbyhuy.github.io/codex-howto/#website","name":"Howto codex","url":"https://builtbyhuy.github.io/codex-howto/","inLanguage":"en","description":"A practical field guide to Codex. ```

Reading curriculum:

```json
{"@context":"https://schema.org","@type":"BreadcrumbList","@id":"https://builtbyhuy.github.io/codex-howto/assets/reading/index.html#breadcrumb","itemListElement":[{"@type":"ListItem","position":1,"name":"Howto codex","item":"https://builtbyhuy.github.io/codex-howto/"},{"@type":"ListItem","position":2,"name":"Reading curriculum","item":"https://builtbyhuy.github.io/codex-howto/assets/reading/index.html"}]}
```

Each lesson adds its actual authored title and canonical lesson URL as position 3. Hash routes are not advertised as separate indexable lesson pages.

## Reproduce the checks

Use an existing Node.js 20+ installation, from the repository root. No account, package installation, paid API or external upload is required for these local checks:

```text
node scripts/build-reading-fallback.cjs --check
node tests/structured-data.cjs
node tests/schema-current.cjs --out schema-controls.json
node tests/schema-generator.cjs --out schema-generator-controls.json
```

Use a fresh output path for each run; reports refuse to overwrite an existing result. Controls operate on disposable copies. The current contract has 55 cases: 47 invalid cases must be rejected, and 8 valid variants must pass. Generator controls cover ordinary authored text, literal replacement tokens/script-closing text, and missing required source language. They also check repeat generation and source preservation. These are bounded checks, not a general HTML sanitizer or universal structured-data validator.

When editing authored home language/description or course data, run `node scripts/build-reading-fallback.cjs`, then run the checks above. The generator changes only the existing home JSON-LD block and the generated reading pages. It preserves lesson data and uses JSON serialization with HTML-safe escaping. A discovered replacement-token bug was reproduced on a temporary copy and corrected by using a literal callback replacement; its valid-text control is retained.

For external validation, use [Schema.org Validator](https://validator.schema.org/) for vocabulary and [Google Rich Results Test](https://search.google.com/test/rich-results) for currently supported features. Submit only the already-public page URL or public HTML, without learner progress or private material. Test the reading index and representative lessons, and rerun local checks across all 61 pages. A WebSite-only home need not produce a Google rich-result item. Search Console access, indexing and actual search appearance require separate evidence.

The release is based on existing GitHub Pages commit `6072d4ec4a4e362f7bb04cf4dc5afeca5fbf935e`. All non-schema bytes of the 62 affected HTML files and the existing learner/runtime/course files are checked for preservation. This bounded release does not reuse the historical source-bound content gate as if it reviewed new content.
