## Understand the concept

Codex is a coding agent that can inspect files, propose changes and run available tools. Begin with the desktop app when you want projects, chats and previews in one workspace. Current official documentation puts a Codex choice inside the ChatGPT desktop app; ordinary Chat or Work instructions are not automatically Codex instructions. A familiar chat box does not prove that the intended folder is open.

Download the desktop installer through the official download link in the app documentation, follow the normal operating-system installation flow, and sign in through the browser. Choose Codex, then open a disposable project folder. The CLI is a separate terminal client; the IDE extension works beside files in your editor. Local clients support ChatGPT sign-in and supported API-key authentication, with different billing and administration implications. Never paste a key into a practice prompt.

Your first success is a trustworthy description of the environment, not an ambitious generated application. A folder named codex-lab containing a short README is enough. Ask what files and tools are actually visible, then compare the answer with your own file browser. Missing access should be reported as missing. A model cannot verify a project merely from its name or from your account being signed in.

### What comes next

Next, choose one small output such as a clearer getting-started document. Name its allowed path, preserve the README as a source, and open the saved result yourself. ### Four names you will encounter

A built-in control operates the client, such as opening status or review. A skill packages a repeated workflow in SKILL.md. A plugin distributes skills and tool connections. An MCP server exposes capabilities a client can discover. They are related, but a plugin or server name is not automatically a working slash command.

In the practice project, the README audit is an ordinary request first, then a local readme-check skill. The fictional ticket remains local data unless an actual available connection retrieves a record. Later stations cover plugin distribution and MCP setup; this first exercise establishes which kind of action you are using.
