# Understand the AGENTS.md instruction chain

## Your outcome

Predict which global, repository and nested instruction files apply to a specific working directory.

## Environment

App / CLI / IDE

## Understand the concept

Codex discovers instructions in a defined chain when it starts. At the global layer, it looks in the Codex home directory, normally .codex in your user home. It prefers a nonempty AGENTS.override.md over AGENTS.md there. At project scope, it walks from the project root toward the current working directory and selects at most one instruction file at each directory level.

Within a directory, the order is AGENTS.override.md, AGENTS.md, then configured fallback filenames. More specific files appear later in the combined instructions and can refine earlier guidance. An override in one directory does not mean that every parent instruction disappears: it replaces the ordinary file selected at that same directory. Keep specialized instructions close to the work they govern rather than changing the global layer for a single project.

This mechanism depends on the actual working directory and project root. A file sitting in a sibling folder is not automatically the governing source for your session. Instruction size is also bounded; the documented combined default limit is 32 KiB. When guidance looks wrong, inspect the selected path and override files, then restart in the intended directory. Do not try to solve discovery problems by repeatedly pasting conflicting instruction copies into chat.


## Explore the details

### Test the override and its absence

The fixture includes root AGENTS.md, ordinary docs guidance, a docs override and contradictory sibling guidance. At docs, the expected project chain retains the root preservation rule and selects the docs override’s short-heading rule. The ordinary docs file and sibling file are counterexamples: neither should be selected at that level.

Remove the override only in the disposable exercise and start a new docs session. The ordinary docs rule should now apply. Compare actual loaded paths, not just a fluent summary. The offline verifier checks these fixture files; it does not claim to have executed Codex discovery.


### Resolve conflicts explicitly

If two instructions appear incompatible, name the files, scopes and concrete conflict. A local test command can refine a root command for a specialized service, but it should not erase unrelated requirements. Put the resolution in the smallest maintainable source when you are authorized to edit it. For a shared repository, preserve existing agreements and ask about a material unresolved conflict instead of silently choosing whichever sentence is easiest to follow.

## Worked reference

### Resolve a same-directory override

Follow examples/hierarchy.md in a disposable copy. This is the expected chain to compare with actual loaded sources, not a claimed live discovery trace.

```text
project/AGENTS.md → preserve WORK-NOTE.md
project/docs/AGENTS.md → descriptive headings
project/docs/AGENTS.override.md → headings under eight words
Working directory: project/docs
```

```text
Root guidance remains applicable.
At docs/, AGENTS.override.md replaces AGENTS.md for that directory.
The ordinary docs heading rule is not loaded alongside its override.
```

An override changes selection at one directory; it does not erase all parent instructions. Use a fresh session and the correct Git project root to test this.

## Common mistakes

- Assuming every AGENTS.md anywhere in the repository loads into every chat.

- Confusing config.toml precedence with Markdown instruction discovery; they are related configuration mechanisms with different purposes.


## Troubleshooting

Both docs files are reported as selected.

The explanation may be guessing rather than reporting actual discovery.

Ask for evidence of selected source paths and verify the documented precedence.

A sibling guideline appears to govern the task.

The working directory or assumed root is wrong.

Inspect the actual directory and repository root before changing guidance.

## Knowledge check

A directory contains both AGENTS.md and a nonempty AGENTS.override.md. Which is selected there?

1. Both are concatenated in that same directory.
2. AGENTS.override.md is selected for that directory.
3. Every parent instruction is automatically discarded.

<details><summary>Reference answer — attempt first</summary>

2. AGENTS.override.md is selected for that directory.

Codex selects at most one file per directory, preferring the override; applicable parent files remain part of the chain.
