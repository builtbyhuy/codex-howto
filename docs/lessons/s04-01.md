## Understand the concept

Delegation is useful when independent work can proceed against a clear shared contract. The capstone has two implementation files: starter/normalize.cjs converts status strings, while starter/report.cjs aggregates already normalized records. Package B does not need to wait for A's implementation because CONTRACT.md defines B's input in advance. The parent retains integration and the final decision about whether the combined result meets the contract.

Read the actual starter before assigning roles. normalizeStatus currently lowercases without trimming; buildReport currently sums every task's minutes. The supplied four-record dataset therefore produces done=1 and doneMinutes=80. The intended result is total=4, done=2 and doneMinutes=55. These distinct causes justify two bounded packages with separate owned files. Assigning both workers the whole lab would introduce an unnecessary collision.

A useful brief names its input, owned file, interface, expected evidence and exclusions. Give A the normalization boundary cases and B the normalized-record requirements. Ask each to return its diff and actual checks. Then run the combined candidate and boundary tests yourself. Sequential implementation is a valid comparison; the local simulation is explicitly not agent activity. State which method actually produced the candidate instead of inferring delegation from a tidy ledger.


## Try the workflow

## Common mistakes

- Splitting a tiny sequential task into many agents without a time or quality benefit.

- Assuming separate agent threads automatically provide separate copies of project files.


## Troubleshooting

Both workers edit the runner to make their code fit.

Ownership and the shared interface were not fixed first.

Restore the runner in the practice copy and assign one owner per implementation file.

Two passing child summaries are treated as final completion.

No integrated candidate was checked.

Run the actual combined files and retain its output; inspect failures even when individual reports sound complete.
