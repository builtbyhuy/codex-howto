# Claude How-To landing stylesheet

`landing.css` is an unmodified, byte-for-byte copy of
`scripts/website_templates/landing.css` in
https://github.com/luongnv89/claude-howto at commit
`188f468893231cbe4525f45e657d554746232072`.

Copied on 22 October 2026. Local integration overrides are kept separately in
`reference-fidelity.css`; the adapted, cancellable interaction implementation is
`reference-motion.mjs`. The upstream font files and Claude brand artwork are not
included in this directory. Fonts used by Codex How-To retain their own OFL
notices under `assets/licenses/`.
