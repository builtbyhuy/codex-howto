Understand the approach

The source uses a model-evaluated prompt hook with an ok/reason answer. Current Codex parses prompt and agent handler types but skips them. A type:prompt file therefore cannot be this course’s active quality gate. Use a supported command handler for a criterion that can actually be checked, and use ordinary model review for judgments the script cannot establish.

The bundled Stop checker reads candidate.md and review-evidence.json in a generated project. It checks two literal headings, the current candidate SHA-256, and two named observations. Missing headings, absent evidence or stale hashes request a focused continuation using decision:block and a reason. Success returns an empty object. A malformed event is diagnosed separately rather than certified as a successful review.

Continuation can repeat agent work, so the checker uses stop_hook_active to bound the classroom retry. If another Stop attempt is already active it reports the unresolved condition and returns without asking for another turn. This is not a built-in model evaluator, and the narrow check does not establish general writing quality. Native activation still requires loaded configuration and reviewed trust.

Make judgment auditable without asking for hidden reasoning

Ask for conclusions, assumptions, the specific evidence used, and short explanations for failed criteria. Do not ask a model to expose private chain-of-thought as a quality signal. A reviewer can be wrong even when its explanation sounds confident, so keep the underlying command result, file excerpt, or interaction trace available. The review improves accountability; it does not replace the user's acceptance of the delivered behavior.

When it does not work

A valid-looking all-passed record still requests continuation.

Likely cause: The actual heading or current artifact hash does not satisfy the contract.

What to try: Inspect and repair candidate.md, then derive a new hash from saved bytes and record actual observations.

The native Stop hook never runs.

Likely cause: The source may not be loaded or the current definition is untrusted; prompt/agent types are skipped.

What to try: Use the generated command configuration and inspect /hooks in a supported client. Keep handler replay and client activation separate.

Common mistakes

  • Claiming a parsed-but-skipped prompt handler provides automatic protection.
  • Using an unbounded Stop continuation that keeps working without a testable stopping condition.
Source mapping & differences · alternative

Codex skips native prompt/agent handlers today. Use explicit evidence-based review, or a separately verified command/MCP evaluation integration, to retain the source's quality-check purpose.
