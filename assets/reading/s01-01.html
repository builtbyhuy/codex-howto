Understand the approach

Codex is a coding agent that can inspect files, propose changes and run available tools. Begin with the desktop app when you want projects, chats and previews in one workspace. Current official documentation puts a Codex choice inside the ChatGPT desktop app; ordinary Chat or Work instructions are not automatically Codex instructions. A familiar chat box does not prove that the intended folder is open.

Download the desktop installer through the official download link in the app documentation, follow the normal operating-system installation flow, and sign in through the browser. Choose Codex, then open a disposable project folder. The CLI is a separate terminal client; the IDE extension works beside files in your editor. Local clients support ChatGPT sign-in and supported API-key authentication, with different billing and administration implications. Never paste a key into a practice prompt.

Your first success is a trustworthy description of the environment, not an ambitious generated application. A folder named codex-lab containing a short README is enough. Ask what files and tools are actually visible, then compare the answer with your own file browser. Missing access should be reported as missing. A model cannot verify a project merely from its name or from your account being signed in.

A first session with a factual answer key

The practice data contains n1, n2, n3 and n4. It is fictional local data; no deployment URL is supplied. README.md recommends npm test, but no package.json exists. A grounded answer distinguishes the project purpose and four records from that unsupported instruction. Do not install a package merely to make the sentence appear valid.

Read notes.json yourself after the response. If the reported directory differs from the returned temporary path, open the right project. A working sign-in proves neither that this folder is selected nor that its contents were inspected.

What comes next

Next, choose one small output such as a clearer getting-started document. Name its allowed path, preserve the README as a source, and open the saved result yourself. Installation, authentication, project access and successful delivery are separate milestones; identify which one failed when troubleshooting.

Four names you will encounter

A built-in control operates the client, such as opening status or review. A skill packages a repeated workflow in SKILL.md. A plugin distributes skills and tool connections. An MCP server exposes capabilities a client can discover. They are related, but a plugin or server name is not automatically a working slash command.

In the practice project, the README audit is an ordinary request first, then a local readme-check skill. The fictional ticket remains local data unless an actual available connection retrieves a record. Later stations cover plugin distribution and MCP setup; this first exercise establishes which kind of action you are using.

Try it step by step

  1. Use the official app instructions for your operating system; if Codex is already installed, inspect it rather than reinstalling.
  2. Create or copy a harmless codex-lab folder with README.md and fictional notes; keep work documents outside the exercise.
  3. Choose Codex and open that folder. In CLI use the intended directory; in IDE confirm the workspace root.
  4. Send the read-only example, open the files it mentions, and correct any mismatch before authorizing a change.

When it does not work

The answer describes another project.

Likely cause: The previous workspace or a broad parent folder is still selected.

What to try: Open the returned practice folder and request a new file-based summary.

The answer supplies a deployment URL.

Likely cause: The model inferred a plausible fact without a source.

What to try: Ask for the exact source; remove the unsupported URL and retain the unknown.

Common mistakes

  • Opening a broad personal folder and assuming every file inside belongs to this task.
  • Treating successful sign-in or a polished answer as evidence that the agent inspected the correct project.
