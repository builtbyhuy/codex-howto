## Full findings-table acceptance

A good README audit cites the relevant file and separates the brief's required behavior from observed implementation. It must not claim npm test ran, invent a deployment address, or call a missing server a successful lookup. See README-REVIEW.md for the full claim/evidence table and HANDOFF.md for the change handoff.
